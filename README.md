## 📋 О проекте

Современное веб-приложение для автоматизации работы сотрудников отделений Почты России. Позволяет вести учёт отправлений, товаров, платежей и формировать отчёты.

### ✨ Ключевые возможности

| Модуль | Описание |
|---|---|
| 📦 **Приём** | Упрощённый приём отправлений, работа с РПО, дополнительные услуги |
| 🛍️ **Товары** | Продажа, остатки, приход, списание, перемещение, инвентаризация |
| 📬 **Вручение** | Вручение РПО, оформление возвратов |
| 🎫 **Коммерческие услуги** | Лотереи, страховки, SIM-карты, телеграммы, ксерокопии |
| 💳 **Платежи** | Пенсии, система «Город», коммунальные платежи |
| 📊 **Отчёты** | Кассовые, по товарам, по почтовым услугам, журнал операций |
| 🔐 **Безопасность** | Авторизация через ключи доступа, синхронизация с Firebase |

---

## 🎨 Особенности интерфейса

- 🌓 **Тёмная / светлая тема** — комфортная работа в любое время суток
- 📈 **Интерактивные графики** — визуализация данных в реальном времени
- 💳 **Корзина** — удобная оплата товаров и услуг (QR, карта, наличные)
- 📱 **Адаптивный дизайн** — работа с любых устройств
- 🔄 **Синхронизация** — данные сохраняются в облаке (Firebase)
